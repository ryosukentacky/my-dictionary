# My辞書 Webアプリ

## 使い方
1. このフォルダをWebサーバーで公開します（GitHub Pages / Netlify / Replit等）。
2. iPhoneのSafariでURLを開きます。
3. 共有 →「ホーム画面に追加」でアプリ風に使えます。

## 単語追加
アプリ下部の「＋ 単語を一括追加 / バックアップ」からJSONを読み込めます。

JSON形式:
[
  {
    "id": "iki",
    "word": "粋",
    "reading": "いき",
    "category": "日本語",
    "content": "A【用語】..."
  }
]

※ブラウザ内で追加したデータは、その端末のlocalStorageに保存されます。
※複数端末で同期したい場合は、次版でクラウドDB（Supabase等）対応にできます。
